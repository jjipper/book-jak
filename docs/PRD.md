# 북작 (BOOKJAK)

> 책을 통해 사람의 취향과 생각이 연결되는, 취향 기반 독서 소셜 플랫폼

---

## 풀고자 하는 문제

1. **책은 많은데 "왜 이 책인지"가 약하다.** 선택이 베스트셀러·제목·표지에 쏠린다.
2. **독서 경험이 개인화·사회화되지 않는다.** 읽고 끝날 뿐, 취향을 분석하거나 사람과 잇는 장치가 없다.
3. **독서 커뮤니티는 진입 장벽이 높다.** 북클럽은 비용·시간·인간관계 부담이 크다.

**해결 방향** — "책"이 아니라 **"책을 읽는 사람의 취향과 생각"을 데이터화**하고, 이를 통해 책 취향의 세계를 넓힌다.

---

## 타겟

- **Primary** — 20~39세, 책을 좋아하고 새로운 책을 찾는 사람. 책을 매개로 한 모임·경험에 관심 있는 사람. 독립 서점을 찾아다니는 사람.
- **Secondary** — 책에 가볍게 관심 있는 사람. 자기 이해·성향 분석을 좋아하는 사람.

**핵심 가치** — 책에 대한 애정을 기반으로 **탐색 + 자기 이해 + 관계 확장**을 한곳에서.

---

## 메뉴 구성

| 메뉴 | 기능 | 노리는 것 |
|---|---|---|
| **홈** | 독서 유형 테스트 + 자유롭게 머무는 커뮤니티 | 유형 테스트로 신규 유입, 책 좋아하는 사람들과 소통하며 체류 |
| **발견** | 제목·표지를 가린 채 요약과 핵심만 보여주는 '블라인드 북'. 궁금한 책을 모아서 확인 | 편견 없이 새 책을 만나는 즐거움 |
| **평가** | 읽은 책 평가 + 새 책 탐색 | 평가 데이터로 선호 분야·작가·취향 분석 |
| **모임** | 일회성 가벼운 참여부터 직접 여는 모임, 책 교환까지 | 믿을 만한 사람들과의 책 모임, 상호 후기로 낯섦 완화 |
| **마이** | 유형 테스트 + 평가 결과로 취향·성향 분석, 뱃지 수집 | 취향 분석의 재미, 뱃지 모으고 자랑하는 재미 |

## 독서 유형 시스템 (BOOK MBTI)

### 4개 축

| 축 | 코드 | 의미 |
|---|---|---|
| 1 | **F** / **T** | 감정형(느끼려 읽음) / 사유형(생각하려 읽음) |
| 2 | **I** / **C** | 몰입형(빠져듦) / 사색형(곱씹음) |
| 3 | **E** / **G** | 도피형(벗어나려) / 성장형(변하려) |
| 4 | **R** / **W** | 현실형(실제 세계) / 환상형(상상 세계) |

→ 4축 조합 = **16유형**
