# 북작 (BOOKJAK) — 디자인 원칙

> 토큰 정본: `src/shared/styles/tokens.css`

## 컨셉

**취향으로 북적이는 독서 취향 소셜.**
비주얼은 "리소 힙-키치" — 차분한 크림 베이스 위에, 쨍한 포인트와 형광 리소 일러스트로 개성을 얹는다.

---

## 필수 규칙

1. **UI 강조는 주황(`--color-accent`) 하나로 통일.**
   버튼·활성 상태·스탯 채움·뱃지 강조 등 모든 UI 강조는 주황만. 파랑·노랑 등 다른 색을 버튼/텍스트/보더에 쓰지 않는다.
   *(리소 일러스트 자체의 형광색은 예외 — UI 요소가 아니라 그림이므로.)*

2. **컴포넌트는 의미 토큰만 참조.**
   `--color-*` · `--font-*` · `--radius-*` · `--space-*` 만 사용. `#hex` 원시값이나 `--p-*` 원시 토큰을 컴포넌트·화면에 직접 쓰지 않는다.

3. **폰트 역할 분리.**
   - `와일드각`(`--font-display`) → 별명·로고·희소도 뱃지 등 "확 튀는 자리"만.
   - `Pretendard`(`--font-body`) → 그 외 모든 텍스트.
   - 본문·설명·버튼 라벨에 와일드각을 쓰면 가독성이 무너진다.

4. **모든 화면은 반응형.**

## 컬러 역할

| 역할 | 토큰 | 용도 |
|---|---|---|
| 페이지 배경 | `--color-bg` (크림) | 앱 전체 바탕 |
| 카드 표면 | `--color-surface` (화이트) | 카드·모달 |
| 컨트롤 면 | `--color-control-surface` | 칩·선택지·인풋·태그. 아래 "면 위계" 참고 |
| 텍스트 | `--color-text` (잉크) | 본문. 순수 검정 대신 따뜻한 잉크 |
| 액션 | `--color-accent` (주황) | 버튼·강조·활성. UI 유일 포인트 |
| 액션 틴트 | `--color-accent-weak` | 선택지 활성 배경 등 연한 강조 |
| 액션 글자 | `--color-accent-text` | 주황 **글자**는 반드시 이것. 화이트·크림·눌린 면 위 대비 4.5:1 (WCAG AA). `--color-accent`·`-hover`는 면·아이콘용 |
| 트랙 | `--color-track` | 진행바·비활성 채움·disabled 버튼 |

## 형태

- **라운드** — 컨트롤(버튼/인풋) `--radius-md`, 카드 `--radius-lg`, 뱃지 `--radius-pill`.
- **테두리 사용 안 함.** 위계는 색(크림/화이트/잉크)으로만 만든다.
- **그림자는 "떠 있는 요소"에만.** 스크롤되는 콘텐츠 위에 뜨는 하단탭·FAB은
  뒤에 뭐가 오는지 알 수 없어 면 색으로는 구분이 불가능하다. 이때만
  `box-shadow: var(--elevation-floating)` (Figma 효과 스타일 `Elevation/떠 있는 요소`).
  카드·컨트롤에는 쓰지 않는다.

### 면(surface) 위계

**컨트롤은 담긴 면과 항상 한 단 달라야 한다.** 이걸 호출부가 신경 쓰지 않도록 `--color-control-surface` 토큰이 상속으로 처리한다.

- 기본값은 화이트 → 크림 페이지 위 컨트롤은 화이트.
- 화이트 면 컨테이너(`.bj-card`, `.bj-question`, `.bj-row`, `.bj-sheet`, `*-card` 계열)가 이 토큰을 크림으로 덮어쓴다 → 카드 안 컨트롤은 크림.
- 컨트롤(칩·선택지·인풋·텍스트에어리어·태그)의 배경은 `--color-bg`/`--color-surface`를 직접 쓰지 말고 **항상 `--color-control-surface`**. 직접 쓰면 크림 위 크림으로 사라진다.

### 테두리를 남기는 예외

면만으로 구분이 불가능한 곳에만 쓴다. 현재 4곳뿐:

- `.bj-topbar__divider` — 세로 구분선
- `.bj-discover-card__reviews` — 카드 내부 가로 구분선
- `.bj-frame` (≥900px) — 데스크톱 "종이 한 장" 바깥 테두리
- **스포트라이트 카드** — 화이트 면 + 주황100 `#FBE5CF` 1px.
  면을 주황 틴트로 깔면 그 위 본문 글자 대비가 깎여서, 면은 기본 카드와 같게 두고
  테두리로만 강조한다. 강조 카드는 한 화면에 하나까지.

포커스·선택 표시는 border가 아니라 **`outline`**(레이아웃 밀림 없음): 인풋 포커스 `outline: 2px solid var(--color-focus-ring)`, 이미지 타일 선택 `outline: 2px solid var(--color-accent)`.

### 컨트롤 규칙

- **버튼** — `min-height: 48px`, `--radius-md`, 무테. primary=주황 채움 / secondary=주황100 채움·주황600 텍스트 / text=`--color-control-surface` 면.
- **disabled** — `opacity` 쓰지 말고 `--color-track` 채움 + `--color-text-caption` 텍스트.
- **섹션 라벨** — 대문자·자간·구분선 폐기. 라벨 텍스트만으로 구획한다.
- **바텀시트** — 그래버 48×4를 `::before`로 자동 생성. 마크업에 넣지 않는다.
- **인풋·텍스트에어리어** — 무테, 라운드 12. 높이 44 / 96. 면은 칩·선택지와 같은 규칙:
  크림 페이지 위는 화이트, 화이트 카드 안은 크림(`--color-control-surface` 상속으로 자동).
  Figma는 `인풋 Input / 크림 위`·`/ 카드안` 두 컴포넌트.
- **앱 폭** — `--app-width: 420px`. 그 아래(폰)는 화면 폭에 맞춰 흐르고, 웹에서는 420에서 멈춘다.
  Figma 시안은 375 프레임(본문 343)이지만 수치는 참고값이고, 코드는 고정폭을 쓰지 않는다.

### 차트

2D 플랫. 입체·그라데이션·그림자를 쓰지 않는다.

- **색은 주황 1색의 농도 단계로만.** 다른 색상을 끌어오지 않는다.
  `#F0562E` → `#F58B6B` → `#F9B9A4` → `#FBDFD5`, 나머지는 트랙색 `#E7E3D9`.
- **트랙은 `#F2EEE4`.** 배경 크림(`#F8F4EB`)과 카드 흰색 어디에 놓여도 보인다.
- 막대는 **양 끝이 둥근 pill**, 트랙 막대를 깔고 그 위에 채운다. 값이 0이어도 자리는 남는다.
- **강조는 하나만.** 최고값 막대만 진한 주황, 나머지는 연한 주황. 축 라벨도 강조 항목만 Bold 주황.
- 축 눈금선·격자는 그리지 않는다. 필요한 숫자는 막대 위에 직접 붙인다.
- 주황 **글자**(값·퍼센트)는 `--color-accent-text`. 면에 쓰는 주황과 다르다.

### 아이콘

- **전부 면(채움)으로 쓴다. 선(스트로크) 아이콘은 쓰지 않는다.**
  일러스트가 두툼한 리소 스타일이라 가는 선 아이콘이 따로 논다.
- 크기 — 하단탭·상단바 24, 행 안 16~20, FAB 22.
- 색 — 기본 잉크900, 보조/비활성 `#90909E`, 활성 주황500.
  카드 푸터의 좋아요·댓글처럼 **보조 정보는 `#C2C2CC`** 로 더 눌러서, 숫자와 같은 톤으로 맞춘다.
- 별점은 모서리가 둥근 일러스트 별. 각진 기하 별을 쓰지 않는다.

## 컴포넌트 · 스타일 규칙

새 UI를 만들기 전, 아래 순서로 판단한다.

1. **기존 컴포넌트로 되는가?** 아래 목록에 있으면 그대로 쓴다.
2. **없으면 만들지 말고 제안 후 확인받는다.** 화면에 인라인 스타일로 우회하지 않는다.

**`src/shared/ui/`** — 공용 UI
`StarRating` · `Stars` · `Button` · `IconButton` · `Chip` · `Sheet` · `Toast` · `Card` · `Row` · `Progress` · `IllustPlaceholder` · `RarityBadge` · `RarityTag` · `SectionLabel` · `Segmented` · `Toggle` · `Input` · `Textarea` · `Callout` · `Check` · `Option`

**`src/widgets/`** — 도메인 위젯
`BookRow` · `ExternalBookRow` · `BlindBookCard` · `BottomNav` · `AuthProvider`

### CSS 배치 규칙

- **컴포넌트 파일 안에서 스타일링하지 않는다.** 스타일은 항상 `.css` 파일로 분리한다.
- **여러 화면이 공유하는 범용 클래스**(버튼·카드·시트 등 atoms)만 `src/shared/styles/components.css`에 둔다. 추가 전, 기존 `.bj-*`로 표현되는지 먼저 확인.
- **특정 화면·기능 전용 CSS**는 `components.css`에 얹지 않는다. 해당 뷰/위젯 폴더에 전용 `.css`를 두고 그 컴포넌트에서 직접 import 한다.
  예: `views/social-hub/ui/SocialHubView.css` → `SocialHubView.tsx`에서 import.
- 클래스 네이밍은 항상 `.bj-*` 접두사 유지.****

## 상태와 방어 (로딩 · 에러 · 긴 텍스트)

모든 목록·상세 화면은 **정상 / 로딩 / 비었음 / 실패** 네 상태를 갖는다. 하나라도 빠지면 미완성으로 본다.

### 로딩

- **스켈레톤을 기본**으로 쓴다. 들어올 내용의 형태(카드·행·표지)를 그대로 흉내 낸다. 스피너는 전체 화면 전환이나 버튼 안처럼 형태를 예측할 수 없을 때만.
- **로딩과 비었음을 절대 같은 화면으로 쓰지 않는다.** 불러오는 중에 "아직 글이 없어요"가 보이면 안 된다. `isLoading` 분기를 `data.length === 0`보다 **먼저** 판단한다.
- 스켈레톤 개수는 **2~3개**. 화면을 가득 채우지 않는다.
- **200ms 미만이면 아무것도 띄우지 않는다.** 깜빡임이 더 거슬린다.
- 추가 로딩(무한 스크롤)은 목록 끝에 스켈레톤 1개. 전체를 스켈레톤으로 덮지 않는다.
- 버튼을 눌러 처리 중일 때는 **버튼만 비활성 + 라벨 유지**. 화면 전체를 가리지 않는다.

### 에러

| 상황 | 표시 방법 | 문구 예 |
|---|---|---|
| 목록을 못 불러옴 | 목록 자리에 인라인 + 다시 시도 | 잠시 후 다시 시도해 주세요 |
| 저장·전송 실패 | 토스트, 입력값은 유지 | 저장하지 못했어요. 다시 시도해 주세요 |
| 네트워크 끊김 | 전체 화면 | 연결이 불안정해요 |
| 삭제된 글·책·모임 | 전체 화면 + 돌아가기 | 삭제되었거나 없는 글이에요 |
| 권한 없음 | 전체 화면 또는 로그인 시트 | 로그인이 필요해요 |

- **재시도 버튼을 반드시 준다.** 사용자가 할 수 있는 일이 없는 화면은 만들지 않는다.
- **입력 중이던 값은 실패해도 지우지 않는다.** 글쓰기·리뷰·댓글은 실패 시 내용을 그대로 남긴다.
- 기술 용어를 노출하지 않는다. 상태 코드·스택·`undefined`는 화면에 쓰지 않는다.
- 외부 API(알라딘) 실패는 **그 영역만** 접는다. 화면 전체를 에러로 덮지 않는다.

### 긴 텍스트

- **한글은 어절 단위로 줄바꿈한다.** 단어 중간에서 끊기면("머릿속/을") 읽기 어렵다.
  `reset.css`의 `body`에 `word-break: keep-all` + `overflow-wrap: break-word`를 **전역으로 한 번만** 선언했고 둘 다 상속되므로, **컴포넌트 CSS에서 다시 쓰지 않는다.** 끊길 곳이 없는 URL·영문은 `break-word`가 받아준다.
- 피그마에는 `keep-all`에 해당하는 속성이 없다. 시안의 본문 텍스트는 **어절 경계에 수동 개행**을 넣어 실제 렌더링과 맞춘다. 문구를 고치면 개행도 다시 잡아야 한다.
- 말줄임은 줄 수를 정해 `-webkit-line-clamp`로 처리한다. **고정 높이로 자르지 않는다.**

| 대상 | 제한 | 넘치면 |
|---|---|---|
| 닉네임 | 입력 12자 | 1줄 말줄임 |
| 글 본문 (목록) | — | 3줄 말줄임 |
| 글 제목 · 추천 제목 | 입력 40자 | 2줄 말줄임 |
| 책 제목 (행) | — | 2줄 말줄임 |
| 저자 · 출판사 | — | 1줄 말줄임 |
| 모임 소개 (상세) | — | 3줄 + 더 보기 |
| 한 줄 리뷰 · 후기 | 입력 100자 | 2줄 말줄임 |
| 글 본문 (작성) | 입력 2000자 | 글자 수 표시 |

- **버튼 라벨은 줄바꿈하지 않는다.** 길어지면 문구를 줄이지, 버튼을 두 줄로 만들지 않는다.
- 숫자는 네 자리부터 쉼표(`1,284`), 999를 넘는 카운트는 `1.2천`으로 줄인다.
- 시간은 방금 / N분 전 / N시간 전 / N일 전, **7일이 지나면 날짜**(2026.9.3). 앱 전체가 같은 규칙을 쓴다.

### 이미지

- 표지·일러스트는 **로드 전 자리를 미리 차지한다.** 비율을 고정해 레이아웃이 밀리지 않게 한다.
- 로드 실패 시 회색 면 + 책 아이콘으로 대체한다. 깨진 이미지 아이콘을 노출하지 않는다.
- 프로필 사진이 없으면 회색 원 + 사람 아이콘.
