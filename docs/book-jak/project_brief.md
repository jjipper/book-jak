# 📚 프로젝트 브리프 — BOOK (가칭)

> 이 문서는 프로젝트 지침용 배경 자료입니다.
> 이 프로젝트에서 작업을 시작할 때 이 문서를 먼저 참고하면 맥락을 바로 잡을 수 있습니다.

---

## 1. 한 줄 정의

**"책을 통해 사람의 취향과 생각이 연결되는 취향 기반 독서 소셜 플랫폼"**

가장 중요한 포지셔닝 (절대 흔들면 안 되는 본질):

- ❌ 책 서비스 아님
- ❌ 독서 기록 앱 아님
- ✅ **"취향을 보여주는 소셜 네트워크"**

핵심 한 문장: *"책을 추천하는 서비스가 아니라, 사람의 생각을 연결하는 서비스다."*

---

## 2. 풀고자 하는 문제

1. 책은 많지만 "왜 이 책을 읽어야 하는지"가 약하다 (제목·베스트셀러 중심 선택)
2. 독서 경험이 개인화·사회화되지 않는다 (읽고 끝, 공유는 단순 리뷰)
3. 독서 커뮤니티는 진입 장벽이 높다 (북클럽 = 비용·시간·인간관계 부담)

해결 방향: **"책"이 아니라 "책을 읽는 사람의 취향·생각"을 데이터화한다.**

---

## 3. 타겟

**Primary**: 20~35세, 감성 콘텐츠 소비자, 독립서점·인스타 감성 유저, 독서모임에 관심은 있으나 부담을 느끼는 사람.

**Secondary**: 책을 많이 읽진 않지만 관심 있는 사람, 자기 이해·성향 분석을 좋아하는 사람.

핵심 특징: **"책 덕후"가 아니라 "감성 + 자기이해 + 공유를 좋아하는 사람"**

---

## 4. 단계별 구조 (Phase 전략)

성장 전략과 제품 빌드 순서를 일치시킨 구조. 콜드 스타트(데이터·네트워크 효과 부재)를 깨는 것이 최우선이라, 책 데이터 없이도 혼자 돌아가고 공유가 곧 유입인 **취향 테스트를 Phase 1로 당겼다.**

- **Phase 1 — 콜드 스타트 해결**: 취향 테스트 → 결과 카드 → 공유
- **Phase 2 — 데이터 생성**: 블라인드 책 카드 + 평가 시스템
- **Phase 3 — 네트워크 효과**: 사람 추천 + 취향 유사도
- **Phase 4 — 커뮤니티**: 질문/답변, 리뷰 확장
- **Phase 5 — 확장**: 랭킹, 게임화, 오프라인 모임

성패를 가르는 단 2가지:
1. **취향 결과를 얼마나 공유하고 싶게 만드느냐** (= 바이럴 엔진)
2. **첫 10초 UX가 재밌느냐** (= 이탈 방지)

## 5. 제품 레이어 (전체 기능 지도)

| 레이어 | 기능 | 핵심 |
|---|---|---|
| Discovery | 블라인드 책 선택 (제목·표지 숨김, 감정 기반 설명) | "책이 아니라 경험을 고르는 구조" |
| Core Data | 독서 후 평가 (0~5점 + 울었음/몰입/생각많아짐/재독의향 등) | 이 데이터가 곧 취향 엔진 |
| Identity | 독서 취향 분석 → 독서 정체성 유형 | "MBTI처럼 공유 가능한 독서 정체성" |
| Social | 사람 기반 추천 (나와 비슷한/다른 사람, 취향 유사도 %) | "책 추천이 아니라 사람 추천" |
| Interaction | 질문 기반 독서 (책 읽고 질문 작성 → 토론) | "리뷰가 아니라 생각의 확장" |
| Retention | 게임화 (랭킹, 배지, 아바타 해금) | "독서 = 기록 + 성장 + 수집" |

> 블라인드 책 선택은 메인 발견 방식보다 **재미 요소(가챠/이벤트)**로 두는 쪽을 검토 중.

## 6. 독서 유형 시스템 (BOOK MBTI) — Phase 1 핵심

### 6.1 4개 축

| 축 | 코드 | 의미 |
|---|---|---|
| 축1 | **F** / **T** | 감정형(느끼려 읽음) / 사유형(생각하려 읽음) |
| 축2 | **I** / **C** | 몰입형(빠져듦) / 사색형(곱씹음) |
| 축3 | **E** / **G** | 도피형(벗어나려) / 성장형(변하려) |
| 축4 | **R** / **W** | 현실형(실제 세계) / 환상형(상상 세계) |

→ 4축 조합 = **16유형**

### 6.2 16유형 목록

| 코드 | 별명 | 이모지 | 희소도 |
|---|---|---|---|
| FIEW | 프로 잠수부 | 🤿 | 4.1% 희귀 |
| FIER | 심해 표류자 | 🏊 | 7.3% 흔함 |
| FIGR | 이야기로 자라는 사람 | 🌱 | 8.1% 흔함 |
| FIGW | 환상 속 나를 찾는 사람 | 🦋 | 3.8% 희귀 |
| FCER | 마음을 데우는 사람 | 🍵 | 6.9% 흔함 |
| FCEW | 여백에 잠기는 몽상가 | 🌫️ | 3.2% 희귀 |
| FCGR | 한 문장에 머무는 사람 | 🌙 | 6.2% 흔함 |
| FCGW | 우화에서 진심을 줍는 사람 | 🦊 | 2.9% 매우 희귀 |
| TIER | 읽고 까먹는 다독러 | 🏃 | 7.8% 흔함 |
| TIEW | 논리적으로 떠나는 사람 | 🚀 | 3.5% 희귀 |
| TIGR | 지식 사냥꾼 | ⚔️ | 9.4% 가장 흔함 |
| TIGW | 가능성을 설계하는 사람 | 🛠️ | 2.6% 매우 희귀 |
| TCER | 거리를 두고 관찰하는 사람 | 🔭 | 4.4% 희귀 |
| TCEW | 머릿속에 우주를 짓는 사람 | 🌌 | 2.3% 최희귀 |
| TCGR | 세상을 해부하는 사람 | 🔬 | 5.7% 흔함 |
| TCGW | 질문만 수백 개 던지는 사람 | ❓ | 2.1% 최희귀 |

> 희소도는 의도적 차등: 흔한 유형(지식 사냥꾼 등)은 공감용, 희귀 유형(질문러·우주 건설러 등)은 자랑용.

### 6.3 네이밍 / 톤 원칙

- **톤**: "책 관련 키워드 + 캐릭터 별명 + 유쾌한 한 줄". (예: 프로 잠수부 = "책 펴는 순간 현실에서 잠수 탐. 호출 금지.")
- 너무 감성적·어려운 단어 지양. "야 이거 봐!!" 하고 던질 수 있는 **유쾌·자학·찐친 놀림** 포인트 필수.
- 공유는 ① 멋있어서(자랑) ② 웃겨서/뜨끔해서(놀림) 두 갈래 — 둘 다 챙긴다.

### 6.4 결과 카드 구성 항목

각 유형 카드는 다음으로 구성 (뇌구조 %와 스탯은 **사람마다 변동** — 같은 유형이어도 숫자 다름):

1. **별명 + 이모지 + 한 줄 + 희소도 등급**
2. **🧠 독서 뇌구조** — % 구성 (마지막 5% 항목은 무조건 웃긴 한 방)
3. **📊 독서 스탯** — 몰입력/인내심/감수성/허세력/완독력 (RPG 능력치 느낌, 친구끼리 숫자 비교용)
4. **🗣️ 입에 달고 사는 말** (어록)
5. **💞 궁합** — 잘 맞는 유형 + 상극 (상극은 티키타카 대사로, 친구 태그 유발). *궁합은 서로 연결되게 설계됨 — A의 짝이 B면 B의 짝에도 A가 등장.*
6. **🏆 칭호** (게임 도전과제)
7. **⚠️ 취급주의** (제품 라벨 패러디 — 경고·부작용)
8. **🔮 독서 운세 + 처방**
9. **📈 1년 후 예언**

> **공유 카드는 2단 구조**:
> - **요약 카드(공유용/인스타)**: 별명 + 한줄 + 희소도 + 뇌구조% + 스탯 → 한 장 이미지
> - **풀 리포트(앱 안)**: 나머지 전부 "더 보기"로 펼침
> - 흐름: 카드 보고 궁금해서 앱 들어옴 → 공유가 곧 유입

## 7. 진단 테스트 설계 (12문항)

- **4축 × 3문항 = 12문항** (이탈 방지를 위해 12개가 마지노선), 다수결로 각 축 글자 결정.
- 비율(3:0, 2:1)은 **변동 스탯·뇌구조% 계산용**으로 저장 — 같은 유형이어도 숫자가 달라지는 재료.
- 가치관 질문은 2지선다, 행동·습관·취향 질문은 4지선다 (선택지 없으면 "나랑 맞는 게 없네" 이탈).
- **책 제목을 묻지 않는다** — 상황·감정·행동으로 묻는다 (진입장벽 제거).
- 4지선다의 C·D 선택지는 **습관 배지 데이터로 재활용** (예: "읽다 놓고 못 읽음" → 미완성 수집가 배지). 진단 한 번에 유형 + 배지 후보 동시 수집.

문항 구성 요약:
- 축1 (F/T): Q1·Q2·Q3 — 2지·2지·2지
- 축2 (I/C): Q4·Q5·Q6 — 4지·4지·4지
- 축3 (E/G): Q7·Q8·Q9 — 2지·2지·4지
- 축4 (R/W): Q10·Q11·Q12 — 4지·4지·2지

> 가입·로그인 없이 바로 시작, 결과 볼 때 가입. 질문 자체가 콘텐츠로 재밌어야 함.

## 8. 디자인 방향 (공유 카드)

- **컨셉**: 독서 트레이딩 카드 (수집 카드). 희소도 뱃지·스탯바·뇌구조 막대 → 자랑·수집 심리 자극.
- **스타일**: 어두운 배경 + 유형별 발광 컬러. 같은 틀, 유형마다 다른 색 → "나는 무슨 색 떴어?"가 공유 트리거.
- 유형별 서식지(habitat) 색 + 움직이는 입자(잠수부=기포, 사냥꾼=불씨 등)로 캐릭터성 부여.
- 캐릭터 자리는 향후 **일러스트**로 교체 예정 (현재는 이모지).
- 폰트: 별명 = Black Han Sans (임팩트), 본문 = Noto Sans KR.

## 9. 경쟁 / 차별점

| 서비스 | 약점 (우리가 파고들 틈) |
|---|---|
| Goodreads | UX 오래됨 |
| 밀리의서재 | 사람(소셜) 없음 |
| 트레바리 | 비쌈 |
| 왓챠피디아 | 책 없음 |

**차별점 4가지**:
1. 책이 아니라 "감정 설명 기반 선택"
2. 리뷰가 아니라 "사람의 생각 데이터"
3. 독서 결과 = 취향 프로필
4. 사람 중심 추천 구조

→ 왓챠피디아·Goodreads·트레바리의 **중간 포지션**을 노린다.

## 11. 알려진 리스크

1. **초기 데이터 부족** → 추천 정확도 낮음 (→ Phase 1 취향 테스트로 우회)
2. **리뷰/평가 작성 귀찮음** → UX 설계가 관건
3. **네트워크 효과 필요** → 초반 성장 어려움 (→ 공유 가능한 취향 카드로 바이럴 유도)

## 12. 작업할 때 기억할 원칙 (요약)

- 본질은 **"취향 소셜 네트워크"** — 기능 추가 시 "이게 사람을 연결하나?"로 검증.
- 모든 결과물은 **공유하고 싶게** + **첫 10초가 재밌게**.
- 유형 네이밍·카피는 유쾌·자학 포인트를 살린다. 너무 감성적이면 톤 다운.
- 뇌구조 %·스탯은 변동값. 궁합은 양방향 연결.
- 진단은 책 제목을 묻지 않고, 선택지로 배지 데이터까지 수집한다.
