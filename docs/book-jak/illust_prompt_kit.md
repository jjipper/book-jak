# 🎨 BOOK — 16유형 일러스트 프롬프트 키트 (리소그래프)

> 검증된 "프로 잠수부" 리소 화풍을 16유형 전체에 일관되게 적용하기 위한 문서.
> 각 유형의 **영문 프롬프트를 그대로 복붙**해서 뽑으면 됩니다. (Copilot / DALL·E 기준)

---

## 1. 화풍 고정 블록 (절대 바꾸지 말 것)

모든 프롬프트 끝에 **항상 똑같이** 붙는 부분입니다. 이게 16개의 통일감을 만듭니다.

```
Authentic risograph print style: only TWO ink colors on cream paper, 
visible halftone dot grain, slight color misregistration, bold flat shapes, 
retro vintage character design, hip indie zine aesthetic. 
Centered dynamic composition. --ar 1:1
```

> 검증 완료: 잠수부가 이 블록으로 완벽하게 나왔음. 캐릭터/구도/색만 바꾸고 이 부분은 고정.

---

## 2. 마스터 프롬프트 템플릿 (복붙용)

```
[캐릭터 + 행동 + 구도].
Two inks: [색1] + [색2].
Authentic risograph print style: only TWO ink colors on cream paper, 
visible halftone dot grain, slight color misregistration, bold flat shapes, 
retro vintage character design, hip indie zine aesthetic. 
Centered dynamic composition. --ar 1:1
```

앞부분 `[캐릭터 + 행동 + 구도]`와 `[색]`만 갈아끼우면 됩니다. 아래 16개에 이미 다 채워뒀어요.

---

## 3. 색 운영 방침 (먼저 읽기)

리소는 2색 인쇄라 색 선택이 곧 분위기예요. 두 가지 방식이 있어요:

- **자유 배분 (이 문서의 기본)**: 유형마다 무드에 맞는 2색. 구분이 잘 되고 다채로움. ← 추천
- **공통 잉크 묶기 (대안)**: 파랑을 16개 공통으로 깔고 두 번째 색만 바꿈. 시리즈 통일감이 극대화되지만 다소 단조로움.

> 통일감은 이미 "리소 질감 + 크림 종이 + 빈티지 캐릭터"가 잡아주니, **자유 배분으로 가도 시리즈로 안 흩어져요.** 색은 카드 디자인의 "유형별 발광 컬러"와도 연결되니, 마음에 안 들면 자유롭게 조정하세요.

## 5. 일관성 유지 팁

- **한 번에 하나씩** 뽑기. 그리드(2x2)로 여러 개 시키면 화풍·디테일이 뭉개짐.
- 화풍 고정 블록은 **글자 하나도 바꾸지 말 것.** 통일감의 핵심.
- 캐릭터가 너무 제각각이면, 잘 나온 잠수부 이미지를 **레퍼런스로 첨부**하고 "same illustration style as the reference" 추가.
- 색이 마음에 안 들면 `Two inks:` 줄만 바꾸면 됨. 화풍은 그대로 유지됨.
- 다 뽑은 뒤 16개를 한 화면에 늘어놓고 **튀는 1~2개만 재생성**하면 시리즈가 깔끔해짐.
- 카드(앱) 안에서는 일러스트 뒤 배경색을 그 유형의 메인 잉크색과 맞추면 카드와 일러스트가 한 몸처럼 보임.

## 6. 작업 순서 제안

1. 잠수부(확정) + 대표 3~4개(사냥꾼·해부형·우주 건설러 등)를 먼저 뽑아 **시리즈가 묶이는지 검증**
2. 묶이면 나머지 전부 진행
3. 안 묶이면 화풍 블록/색 방침을 미세 조정 후 재검증
