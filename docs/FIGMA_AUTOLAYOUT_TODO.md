# 피그마 — Auto Layout 사이징 정리 목록

현재 시안은 대부분의 요소가 **고정폭(Fixed)** 으로 들어가 있다.
값 자체는 맞춰놨기 때문에 보이는 결과는 정상이지만, 프레임 폭을 바꾸면
따라오지 않는다. 아래 목록대로 **Fill container / Hug contents** 로 바꾸면
폭 변경이 한 번에 전파된다.

> 왜 내가 직접 못 바꿨나 — Figma 플러그인 브리지(`ClaudeTalkToFigma`)에
> `layoutSizingHorizontal` / `layoutAlign` 을 설정하는 함수가 없다.
> `set_auto_layout` 은 방향·간격·패딩만 다루고, `resize_node` 는 고정값만 쓴다.
> 그래서 값은 맞춰두고 모드 전환만 남겨둔다.

---

## 기준

| 성격 | 사이징 | 예 |
|---|---|---|
| 화면 폭을 꽉 채우는 것 | **Fill container** | 카드, 섹션, 인풋, 블록 버튼, 리스트 행, 상단바 |
| 글자 길이만큼만 차지하는 것 | **Hug contents** | 칩, 배지, 작은 버튼, 라벨, 숫자 |
| 비율·정사각 고정 | **Fixed** | 아바타, 표지 썸네일, 아이콘, FAB, 차트 |

화면 폭 375 · 좌우 패딩 16 → 본문 영역 **343**
카드 내부 패딩 16 → 카드 안 본문 영역 **311**

### 화면에 직접 그려진 프레임

각 화면 `content` 안의 아래 이름을 가진 프레임들 — 전부 Fill container.

- `section 인기글`, `section 모든 글`, `섹션 모임 열기`
- `섹션 줄거리`, `섹션 작가`, `섹션 이런 책이에요`, `섹션 다른 독자들은 이 책도 좋아해요`
- `card 사람 추천`, `people rail`
- `별점 리뷰 카드`, `작가 카드`, `후기 카드`
- `배지 카드`, `보관함 카드`, `나의 활동 카드`, `궁합 카드`, `네 축 카드`,
  `취향 리포트 카드`, `장르 비율 카드`, `발견 성향 카드`, `취향 키워드 카드`
- `my-profile`, `my-result-card`, `book-head`, `login-hero`, `login-action`
- `genre-bars`, `report-stats`, `affinity-center`, `겹치는 취향`, `동시에 좋아하는 책`
- `장르 칩 레일`, `메타 칩 레일`, `평가 리스트`, `배지 그리드`, `write-sheet` 내부 입력부

## 2. Hug contents 로 바꿀 것

| 대상 | 노드 | 비고 |
|---|---|---|
| 칩 Chip (기본/카드안/활성/아이콘) | `10:688`~`10:691` | 라벨 14로 키움, 높이 32 |
| 유형 배지 TypeBadge | `12:960` | 코드 길이가 3~4자로 다름 |
| 작은 버튼 ButtonSmall | `88:1410` | 라벨 길이 제각각 |
| 토큰 배지 TokenBadge | `2004:2053` | |
| 필터 셀렉트 FilterSelect | `2004:2054` | |
| `sort chips`, `옵션 칩`, `키워드 칩`, `정렬 칩` | 화면별 | 가로 Hug + 내부 Fixed 칩 |
| 모든 텍스트 노드 중 **한 줄짜리** | | 제목·라벨·숫자·시간 |

본문처럼 **여러 줄로 흐르는 텍스트**는 Hug가 아니라
`Fill container` + `Auto height` 로 둬야 줄바꿈이 제대로 먹는다.
해당: `post-card__content`, `book-description`, `report__desc-body`,
`qna__text`, `empty__desc`, `rec-card__mood`, `blind-card__desc`.

## 3. Fixed 로 유지할 것

아바타(28·40·48), 책 표지(48×64 / 52×70), 아이콘(16·24·30),
FAB(56), 도넛·레이더·게이지 차트, 배지 메달(88×112), 일러스트 프레임.

## 작업 순서 (권장)

1. 공용 컴포넌트 마스터부터. 마스터를 고치면 인스턴스에 전파된다.
2. 단, **해당 속성에 override가 박힌 인스턴스는 전파되지 않는다.**
   이전에 인스턴스마다 값을 직접 찍어둔 것들이 그렇다.
   막히면 그 인스턴스를 우클릭 → `Reset all overrides` 후 내용만 다시 넣는다.
3. 화면별 프레임은 섹션(1 시작하기 → 7 상태) 순서대로.

## 참고 — 이미 정리된 것

- 전 화면 패딩 상하좌우 **16** 통일, 본문 영역 343 / 카드 안 311
- 335·337·340·342·353으로 흩어져 있던 컴포넌트 폭을 전부 343으로 통일 (2026-10)
- 질문 행 QnaRow 폐기 → 댓글 행 CommentRow 재사용 (답글은 paddingLeft 48)
- 코드 앱 폭은 `--app-width: 420px` — 시안 375는 참고값
- PostCard 인스턴스 32개를 override 없는 새 인스턴스로 교체
  (글쓴이 12 · 시간 12 · 본문 14, 하트·댓글 아이콘 면 처리 + `#C2C2CC`, 숫자 `#9A9AA4`)
- 칩 라벨 12 → 14, 칩 높이 28 → 32
- 한글 본문은 어절 경계에 수동 개행 — 자세한 건 `DESIGN.md`의 "긴 텍스트"
