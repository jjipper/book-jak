# 북작 (BOOKJAK) — 디자인 원칙

> Claude Code 필독. 새 화면·컴포넌트를 만들 때 이 규칙을 반드시 지킬 것.
> 이 문서는 "왜 이렇게 생겼나"의 근거이자, 일관성을 지키는 가드레일입니다.
>
> 토큰 정본은 `src/shared/styles/tokens.css`. 이 문서의 예시는 v2 의미 토큰
> (`--color-accent`(강조)·`--color-border-soft`(헤어라인)·`--color-border`(강조 잉크선) 등)
> 기준으로 쓴다. `--color-action`·`--color-border-strong`·`--radius-control` 등 v1 이름은
> 별도 폴더로 격리돼 있지 않고, 아직 이관되지 않은 뷰의 인라인 스타일이 참조하는 별칭(alias)으로
> 같은 `tokens.css` 안에 남아 있다. 새 코드는 v2 이름을 쓰고, 기존 v1 이름이 있는 코드를
> 건드릴 일이 있으면 v2로 옮긴다.

## 0. 한 줄 정체성
**북작 = 취향으로 북적이는 독서 취향 소셜.**
비주얼은 "리소 힙-키치": 차분한 크림 베이스 위에, 쨍한 포인트와 형광 리소 일러스트로 개성을 얹는다.

---

## 1. 절대 규칙 (어기면 톤이 무너짐)

1. **UI에는 주황(`--color-accent`) 단일 포인트만.**
   버튼·활성 상태·스탯 채움·뱃지 강조 등 모든 UI 강조는 주황 하나로 통일.
   파랑·노랑 등 다른 색을 UI 요소(버튼/텍스트/보더)에 쓰지 말 것.

2. **형광 리소 2색(`--p-riso-*`)은 오직 `.bj-illust` 안에서만.**
   형광주황·코발트블루는 캐릭터 일러스트, 서식지 배경, 로고 마크 같은
   "그림" 영역 전용. UI 컨트롤에는 절대 쓰지 않는다.

3. **그림자 없음.** 위계는 색(크림/화이트/잉크)과 테두리로만 만든다.
   `box-shadow`는 인풋 포커스 링 외에는 쓰지 않는다.

4. **컴포넌트는 의미 토큰(`--color-*`, `--font-*`, `--radius-*`)만 참조.**
   `#hex` 원시값이나 `--p-*` 원시 토큰을 컴포넌트/화면에 직접 쓰지 말 것.

5. **폰트 역할 분리.**
   - `와일드각`(`--font-display`) → 별명·로고·희소도 뱃지 등 "확 튀는 자리"만.
   - `Pretendard`(`--font-body`) → 그 외 모든 텍스트.
   본문·설명·버튼 라벨에 와일드각을 쓰면 가독성이 무너진다.

---

## 2. 컬러 역할

| 역할 | 토큰 | 용도 |
|---|---|---|
| 페이지 배경 | `--color-bg` (크림) | 앱 전체 바탕 |
| 카드 표면 | `--color-surface` (화이트) | 카드·모달 |
| 텍스트 | `--color-text` (잉크) | 본문. 순수 검정 대신 따뜻한 잉크 |
| 액션 | `--color-accent` (주황) | 버튼·강조·활성. UI 유일 포인트 |
| 액션 틴트 | `--color-accent-weak` | 선택지 활성 배경 등 연한 강조 |

---

## 3. 타이포 스케일

| 클래스 | 폰트 | 크기/굵기 | 용도 |
|---|---|---|---|
| `.bj-display--xl` | 와일드각 | 32 | 로고, 결과 카드 별명 |
| `.bj-display--lg` | 와일드각 | 24 | 유형 별명(리스트) |
| `.bj-h1` | Pretendard | 800·24 | 섹션 제목 |
| `.bj-h2` | Pretendard | 700·18 | 소제목 |
| `.bj-body` | Pretendard | 400·16 | 본문 |
| `.bj-caption` | Pretendard | 400·13 | 부가 정보·희소도 % |

---

## 4. 형태

- 라운드: 컨트롤(버튼/인풋) `--radius-md`(12px), 카드 `--radius-lg`(16px), 뱃지 `--radius-pill`.
- 테두리: 크림 위 헤어라인 `--color-border-soft`, 강조 테두리는 잉크 `--color-border`.
- 단면 테두리(border-left 등)에는 라운드를 주지 않는다.

---

## 5. 시그니처 — 리소 미스레지스트레이션

로고 마크·강조 아이콘은 같은 도형을 두 색으로 살짝 어긋나게 겹쳐 "리소 색 어긋남"을 표현한다.
`.bj-riso` 컴포넌트 사용. 오프셋은 `--riso-offset`(3px). 이게 "북작다움"의 핵심 시각 장치.
이모지는 쓰지 않는다 — 캐릭터 자리는 형광 리소 일러스트로 채운다.

---

## 6. 카피 톤 (UI 문구)

- 유쾌·자학·찐친 놀림. 너무 감성적이면 톤 다운.
- 버튼은 동사로 시작, 문장부호 없이. ("테스트 시작", "결과 공유")
- 빈 화면·에러도 사과 대신 방향 제시. 유쾌하게.
- 별명·어록은 개성 있게, 정보 텍스트는 깔끔하게 — 두 톤을 섞지 않는다.
